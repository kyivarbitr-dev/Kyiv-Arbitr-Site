# Нормальна адреса сайту: домен і хостинг

## Скільки це коштує

Сайт статичний (HTML, CSS, JavaScript без бази даних), тому **платний хостинг не потрібен**. Безкоштовно його розміщують Netlify, GitHub Pages або Cloudflare Pages. Платити доведеться лише за **домен** (адресу сайту), приблизно раз на рік.

Орієнтовні ціни реєстрації на рік за даними сайтів реєстраторів, які я знайшов під час підготовки інструкції. Вони змінюються, часто діють акції на перший рік, а продовження буває дорожчим. Перед оплатою порівняйте ціну в кошику.

| `.com.ua` | Найпоширеніша в Україні, відкрита для всіх | близько 400–720 грн |
| `.kyiv.ua` | Регіональна, підкреслює Київ | близько 400–540 грн |

**Рекомендація:** `.com.ua` або `.kyiv.ua`. Реальний бюджет приблизно **400–750 грн на рік**, хостинг безкоштовний.

## Як обрати назву

Назва має бути короткою, латиницею, без помилок у написанні. Приклади ідей (перевірте, чи вільні):
`rakovskyi.com.ua`, `kyivarbitr.com.ua`, `arbitr-rakovskyi.com.ua`, `rakovskyi.kyiv.ua`.

## Як обрати реєстратора

- Реєструйте домен **на себе** (у вашому акаунті), а не на сторонню особу.
- Перевірте, що реєстратор показує повну вартість продовження.
- Має бути керування DNS-записами (у більшості реєстраторів воно є безкоштовно).
- Захист персональних даних у реєстрі (WHOIS privacy) бажаний, у деяких реєстраторів він безкоштовний.

## Крок 1. Тимчасово зробіть адресу коротшою (безкоштовно)

Це не власний домен, але адреса стане набагато кращою за `tangerine-paprenjak-3746b5.netlify.app`.

1. Netlify → ваш проєкт → **Project configuration** → **General** → **Project details**.
2. Натисніть **Change project name** і введіть, наприклад, `kyiv-arbitr`.
3. Адреса стане `kyiv-arbitr.netlify.app` (якщо назва вільна).

## Крок 2. Купіть домен

1. Відкрийте сайт обраного реєстратора й перевірте, чи вільна назва.
2. Додайте домен у кошик, створіть акаунт, оплатіть.
3. Збережіть доступ до акаунта реєстратора: це ваша власність.

## Крок 3. Підключіть домен до Netlify

1. Netlify → проєкт → **Domain management** → **Add a domain** (або **Add a domain you already own**).
2. Введіть свій домен (наприклад, `rakovskyi.com.ua`) і підтвердьте.
3. Netlify запропонує один із двох способів підключення.

**Спосіб А (простіший): DNS-записи в реєстратора.**
1. У Netlify відкрийте розділ DNS-налаштувань цього домену й перегляньте значення, які він вимагає: зазвичай запис типу **A** (або **ALIAS**) для основного домену й запис **CNAME** для `www`, що вказує на ваш `…netlify.app`.
2. У панелі реєстратора знайдіть **керування DNS** (DNS-записи) і додайте саме ті значення, які показав Netlify. Не копіюйте значення з інструкцій третіх осіб: Netlify показує точні адреси для вашого проєкту.

**Спосіб Б: Netlify DNS.**
1. Netlify покаже власні сервери імен (name servers).
2. У реєстратора замініть сервери імен домену на ті, що показав Netlify.

4. Зачекайте від кількох хвилин до доби: DNS-зміни поширюються не миттєво.
5. У Netlify, розділ Domain management → **HTTPS**, переконайтесь, що сертифікат видано (кнопка Verify DNS configuration / Provision certificate), і ввімкніть **Force HTTPS**, якщо така опція є.
6. Оберіть основну адресу: з `www` або без. Netlify автоматично перенаправляє другу на основну.

## Крок 4. Оновіть файли сайту

Після підключення домену замініть `YOUR-DOMAIN.COM.UA` на вашу адресу в файлах `robots.txt` і `sitemap.xml`. У кожному HTML-файлі розкоментуйте рядок canonical у `<head>` і впишіть адресу (наприклад, `https://rakovskyi.com.ua/about.html`). Збережіть зміни в GitHub, і Netlify оновить сайт автоматично.

## Крок 5. Повідомте Google

1. search.google.com/search-console → додайте ресурс за вашим доменом.
2. Підтвердьте право власності через DNS-запис (його додають так само, як у кроці 3).
3. У розділі Sitemaps додайте `sitemap.xml`.

## Якщо ви хочете використовувати GitHub Pages замість Netlify

1. GitHub → репозиторій → **Settings → Pages → Custom domain** → введіть домен → Save.
2. У реєстратора додайте DNS-записи, які покаже GitHub (у документації GitHub Pages вказано актуальні значення).
3. Після видачі сертифіката ввімкніть **Enforce HTTPS**.

## Типові проблеми

- **Домен не відкривається.** Зачекайте до доби. Перевірте, що записи в реєстратора збігаються з тими, що показує Netlify.
- **Помилка сертифіката.** Зачекайте, поки Netlify видасть сертифікат (розділ HTTPS), і повторіть перевірку DNS.
- **Відкривається стара адреса.** Очистіть кеш браузера (Ctrl+F5) або відкрийте сайт в анонімному вікні.
- **Продовження.** Увімкніть автопродовження домену в реєстратора й слідкуйте за оплатою, бо прострочений домен можуть зареєструвати інші.
