# Сайт арбітражного керуючого: інструкція із запуску

Це статичний сайт (HTML, CSS, JavaScript) без збирання. Його можна розмістити на GitHub Pages, Netlify або Vercel без змін.

## Структура

```
index.html       Головна: курси НБУ, криптовалюти, компетенції, останні новини
about.html       Про мене
services.html    Послуги, судові витрати, процес роботи
analytics.html   Аналітика й запитання
news.html        Новини
links.html       Корисні посилання: суди, реєстри, Prozorro.Sale, джерела курсів
en/              англійська версія сайту (ті самі назви файлів)
privacy.html     Політика конфіденційності
thanks.html      сторінка «Дякуємо» після надсилання форми
contacts.html    Контакти, форма, карта
css/style.css    стилі
js/config.js     НАЛАШТУВАННЯ (форма, аналітика, карта, віджети)
js/app.js        меню, форма, аналітика, карта
js/widgets.js    віджети НБУ і криптовалют
js/news.js       новини
js/reveal.js     плавна поява блоків при скролі
news/news.json   ВАШІ НОВИНИ (цей файл ви оновлюєте)
assets/          фото й свідоцтво
DOMAIN-GUIDE.md  домен, ціни, підключення до Netlify
favicon.svg, 404.html, robots.txt, sitemap.xml
.nojekyll, netlify.toml, vercel.json   службові файли хостингів
```

Шапка й футер повторюються в кожному HTML-файлі. Якщо змінюєте контакти чи меню, оновіть їх у всіх 7 українських файлах і в 7 файлах папки en/.

## Що налаштовується в js/config.js

| Параметр | Призначення |
|---|---|
| `GOOGLE_FORM_URL` | Адреса вбудованої Google Form. Порожньо: працює власна форма сайту через Netlify Forms |
| `GA4_ID` | Ідентифікатор Google Analytics 4 (`G-XXXXXXXXXX`). Порожньо: аналітика вимкнена |
| `MAP_EMBED_URL` | Необов'язково: власний код карти з Google Maps |
| `NBU_CURRENCIES` | Валюти для показу (за замовчуванням USD, EUR, GBP, PLN) |
| `CRYPTO` | Криптовалюти (BTC, ETH, XRP) |

Якщо вмикаєте Google Analytics, розгляньте банер згоди на cookie й політику конфіденційності (узгодьте з юристом).

## Варіант A. GitHub Pages

1. Створіть акаунт на github.com і новий репозиторій (наприклад, `rakovskyi-site`).
2. Завантажте всі файли з цієї папки в репозиторій (Add file → Upload files). Службовий файл `.nojekyll` теж.
3. Settings → Pages → Source: Deploy from a branch → гілка `main`, папка `/ (root)` → Save.
4. Через 1–2 хвилини сайт з'явиться за адресою `https://ваш-логін.github.io/rakovskyi-site/`.
5. Власний домен: у тому ж розділі Pages вкажіть Custom domain і додайте DNS-записи в реєстратора (GitHub покаже, які саме).

Примітка: для проєктного репозиторію сторінка 404 не знайде кореня `/`; з власним доменом проблеми немає.

## Варіант B. Netlify

Найпростіше: відкрийте app.netlify.com/drop і перетягніть **цю папку**. Сайт одразу отримає тимчасову адресу.
Через репозиторій: Add new site → Import from Git → Build command порожньо, Publish directory `.`.
Власний домен: Site configuration → Domain management → Add a domain.

## Варіант C. Vercel

1. Завантажте файли в репозиторій GitHub.
2. На vercel.com: Add New → Project → Import Git Repository.
3. Framework Preset: **Other**. Build Command і Output Directory залишіть порожніми. Deploy.
4. Власний домен: Project → Settings → Domains.

## Розділ «Новини»: як додавати матеріали щодня

Новини зберігаються в одному файлі `news/news.json`. Сайт читає його при відкритті сторінки й показує новини від найновіших до найстаріших (по 6 штук, далі кнопка «Показати ще»).

### Спосіб 1. Редактор новин (найзручніше)

1. Відкрийте файл `news-editor.html` у браузері (двічі клацніть по ньому на комп'ютері). Він працює локально й нічого нікуди не надсилає.
2. Натисніть «Оберіть файл» і завантажте поточний `news/news.json`.
3. Заповніть дату, заголовок, короткий опис, за потреби повний текст, тему й посилання на джерело. Натисніть «Додати новину».
4. Натисніть «Завантажити news.json» і замініть ним файл `news/news.json`:
   - **GitHub:** відкрийте репозиторій → папка `news` → файл `news.json` → «Edit» (олівець), вставте новий вміст (кнопка «Копіювати» в редакторі) → Commit changes. Сайт оновиться автоматично за 1–2 хвилини.
   - **Netlify / Vercel із GitHub:** так само, оновлення публікується автоматично.
   - **Netlify Drop:** перетягніть оновлену папку сайту ще раз.

### Спосіб 2. Вручну

Відкрийте `news/news.json` у будь-якому текстовому редакторі й додайте об'єкт у такому форматі (між об'єктами ставте кому, останній без коми):

```json
{
  "id": "2026-10-06-1",
  "date": "2026-10-06",
  "tag": "Банкрутство",
  "title": "Заголовок новини",
  "summary": "Одне-два речення для картки.",
  "text": "Повний текст.\n\nДругий абзац.",
  "link": "https://...",
  "linkLabel": "Джерело"
}
```

Обов'язкові поля: `date`, `title`. Поля `summary`, `text`, `tag`, `link`, `linkLabel` необов'язкові.

### Корисні можливості

- **Відкладена публікація.** Новина з майбутньою датою не показується до цього дня. Можна підготувати кілька новин наперед.
- **Безпека.** Текст виводиться як звичайний текст, а посилання приймаються лише з `http://` і `https://`.
- Новини завантажуються скриптом, тому пошукові системи індексують їх гірше за звичайні сторінки. Якщо важливо, щоб окремі матеріали знаходили через пошук, їх варто оформити окремими сторінками.

### Про зміст новин

- Додавайте тільки те, що ви готові підписати власним іменем. Для кожної новини про закон, практику чи торги вказуйте посилання на офіційне джерело.
- Не копіюйте чужі тексти. Переказуйте своїми словами й посилайтесь на першоджерело.
- Без гарантій результату, обіцянок і тверджень про власні досягнення. Дотримуйтесь вимог до реклами юридичних послуг, а сумнівні формулювання узгоджуйте з юристом.
- Ідеї для щоденних тем: роз'яснення процедур (на основі Кодексу з процедур банкрутства), нова судова практика з посиланням на рішення, огляд відкритих торгів, корисні сервіси (як перевірити справу, реєстри), відповіді на типові запитання клієнтів.

## Після підключення домену

1. Замініть `YOUR-DOMAIN.COM.UA` у `robots.txt` і `sitemap.xml` на свою адресу.
2. У кожному HTML-файлі розкоментуйте рядок canonical і впишіть адресу сторінки. Детальніше в `DOMAIN-GUIDE.md`.
3. Google Search Console: додайте ресурс, підтвердіть через DNS, подайте `sitemap.xml`.

## Форма звернення

1. Створіть Google Form: ім'я, телефон, email, тип клієнта, опис ситуації, згода на обробку даних.
2. Forms → Надіслати → вкладка `<>` → скопіюйте адресу з `src="..."`.
3. Вставте її в `GOOGLE_FORM_URL` у `js/config.js`.
4. У Forms увімкніть зв'язок з Таблицями й сповіщення про нові відповіді.

## Віджети: як вони працюють і що перевірити

Дані завантажуються у браузері відвідувача прямо з відкритих API:

- **Курси НБУ:** `bank.gov.ua/NBUStatService/v1/statdirectory/exchange?json`.
- **Криптовалюти:** CoinGecko (основне джерело, USD і UAH), у разі збою Binance (USD, гривня за курсом НБУ).

Якщо джерело недоступне, віджет показує повідомлення з посиланням на офіційний сайт, а решта сайту працює як звичайно.

**Обов'язково перевірте після публікації** (відкрийте сайт, натисніть F12 → вкладка Console/Network):

1. Чи завантажуються курси НБУ і криптовалюти. Якщо браузер блокує запит через CORS, віджет покаже посилання замість даних.
2. Усі посилання на сторінці «Корисні посилання» й адресу карти (чи правильна точка на мапі).

Безкоштовні API мають обмеження частоти запитів (особливо CoinGecko). Сайт кешує відповіді в браузері й оновлює криптокурси раз на дві хвилини.

## Перед запуском

- Юрист переглядає всі тексти, блок судових витрат і юридичні примітки.
- Номер ІПН на сайті не публікується.
- Перевірка на телефоні, планшеті й комп'ютері.
- Соцмережі: додайте посилання у футер і блок «Контакти» (закоментований приклад є в `contacts.html`).


## Плавна поява блоків при скролі

Щоб блок з'являвся анімовано, додайте йому клас `scroll-reveal`. Затримку можна задати вручну: `style="--delay: 0.2s"`. Якщо затримку не задано, блоки, що одночасно входять в екран, з'являються по черзі з кроком 100 мс. Перший екран (hero), шапка й футер не анімуються. Якщо в системі відвідувача увімкнено обмеження руху, анімація вимикається.


## Англійська версія

Англійська версія лежить у папці `en/` і має ті самі назви файлів. Перемикач UA / EN у шапці веде на відповідну сторінку іншою мовою. Якщо змінюєте текст українською, оновіть і англійську сторінку.

Щоб новина з'явилася в англійській версії, додайте в `news/news.json` поля з суфіксом `_en`: `title_en`, `summary_en`, а за потреби `text_en`, `tag_en`, `linkLabel_en`. Новина без `title_en` показується лише українською.


## Форма звернення (Netlify Forms)

Форми на сторінках `contacts.html` (назва `zvernennya`) та `en/contacts.html` (назва `enquiry-en`) працюють через Netlify Forms. Заявки зберігаються в кабінеті Netlify: Site → Forms. Від спаму захищає приховане поле `bot-field` і вбудований фільтр Netlify.

Один раз після першої публікації:
1. У кабінеті Netlify відкрийте розділ Forms і ввімкніть виявлення форм (Enable form detection), якщо воно вимкнене.
2. Опублікуйте сайт ще раз (Deploys → Trigger deploy), щоб Netlify знайшов форми.
3. Налаштуйте сповіщення: Forms → Form notifications → Email notification → kyivarbitr@gmail.com.

Форма працює лише на Netlify. На GitHub Pages чи при відкритті файлу з комп'ютера відвідувач побачить повідомлення з телефоном і email.


## Новини з картинками

Картинки до новин лежать у папці `news/img/`. У `news/news.json` у новині вказується поле `"image": "img/назва-файлу.jpg"` (шлях відносно папки `news`) і, за бажанням, `"image_alt"` / `"image_alt_en"` з описом картинки. Рекомендований розмір картинки 1200×630, формат JPG, до 150 КБ. Новина без поля `image` показується без картинки.
